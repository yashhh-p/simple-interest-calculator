# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest per year
- Time period in years

## Output
- Simple interest
- Total amount (Principal + Simple Interest)

## Example
Principal = 1000  
Rate = 5%  
Time = 2 years  

Simple Interest = 100  
Total Amount = 1100

## Purpose
This project demonstrates the basic calculation of simple interest using the given inputs.
